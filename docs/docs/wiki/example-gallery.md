# Example Gallery

A showcase of projects built with Voxelize. Submit your project by opening a pull request!

## Featured Projects

### Official Examples

#### Basic Demo
The default Voxelize demo showcasing core features.

- **Source**: `examples/client/`
- **Features**: Basic world, block interaction, multiplayer
- **Tech**: TypeScript, Three.js

#### Multiplayer Demo
Demonstrates multiplayer capabilities with multiple clients.

- **Source**: `examples/client/`
- **Features**: Real-time multiplayer, entity synchronization
- **Tech**: WebSockets, Protocol Buffers

## Community Projects

*Add your project here! Open a PR with:*
- Project name and description
- Screenshot/GIF
- Link to repository or demo
- Key features
- Technologies used

## Submission Guidelines

To add your project:

1. Fork the repository
2. Add your project to this page following the format:
   ```markdown
   ### Your Project Name
   Brief description of your project.
   
   - **Demo**: [Link to demo](url)
   - **Source**: [Link to repo](url)
   - **Features**: Feature list
   - **Tech**: Technologies used
   ```
3. Include a screenshot (add to `docs/static/img/examples/`)
4. Open a Pull Request

## Project Ideas

Looking for inspiration? Here are some project ideas:

- **Survival Game**: Health, hunger, crafting system
- **Creative Mode**: Block palette, building tools
- **Adventure Map**: Custom terrain, quests, NPCs
- **Minigames**: Parkour, PvP, puzzle games
- **Educational**: Teaching voxel concepts, procedural generation
- **Art Projects**: Voxel art, interactive installations
